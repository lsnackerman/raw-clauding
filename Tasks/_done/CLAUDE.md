# Completed tasks

Tasks land here automatically when their status changes to `done`: on the save, and again at the end of every turn.

These aren't dead files. Completed task docs hold the reasoning behind decisions: the observations, the friction, the threads that emerged while working. The decisions end up in the code or the system, but the *why* lives here.

When you pick up related work later, `/pickup` can check the battle history here, scanning completed tasks for hard-won solutions before you reach for the knife on something that already has scars.
