# Projects

Your active work. Each project gets a folder when it's big enough to need one.

No rules here. Organize however fits how you think. Some people create `work/`, `people/`, `life/`, `school/`; others organize by project name. The structure will tell you what it needs.

`_inbox/` is already here. Drop things that need routing, and file them out as you go (it trends toward zero).
