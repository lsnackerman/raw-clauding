# _inbox — Drop things that need routing

The underscore = process this. Contents leave through routing, not accumulation, so this folder trends toward zero.

Drop anything here that doesn't have a home yet: a quick capture, a screenshot, a file you pulled in, a thought you'll route later. Then during a session or at `/wrap`, move each thing to where it belongs.

**When something's been here a while.** If a file has sat for a couple of weeks and you keep not knowing where it goes, that's a signal, and usually it means the right home doesn't exist yet, not that you forgot to file it. That's worth a conversation with the AI: maybe it wants a new folder, a new project, or it was never worth keeping.
