# Concepts — ambient ping-layer for frames you already hold

*The conceptual sibling of `MEMORY.md`. MEMORY pings operational shortcuts, this pings **conceptual frames** you've already thought through. Auto-loads so the frames sit warm: when a riff drifts toward an entry's *"ping when riffing"* trigger, that's the doorbell to re-walk the thing **knowing it exists** (ping, don't prime). It catches **re-derivation**, meaning re-walking a frame you already hold, phrased differently, so search never connects them.*

**This file starts nearly empty on purpose. Grow it from your own catches, scalpel not scale, never fill it complete** (a complete index becomes wallpaper and stops firing). How it fires, how to grow + sharpen it, the entry format, and what it does *not* catch: **`Core/practice/concepts-layer.md`**. Read that before adding entries.
