# Practice — ways of working

*Enact these *during* the work. How to actually run sessions, get set up, and work well with the AI.*

Different from `foundations/` (why it works) and `mechanics/` (how the machine works), practice is the *doing*: getting started, running the session loop, knowing when to reach for which model, handing off cleanly between sessions.

## The two loops (start here)

The whole system runs on two loops:

- **[session-loop.md](session-loop.md)** — `/pickup` → work → `/wrap` → repeat. Bridges sessions so each one starts warm instead of cold.
- **[explore-loop.md](explore-loop.md)** — curiosity → `/explore` → reserve → apply. Deepens any topic so you find more than you put in.

Together they cover session-bridging AND topic-deepening, which is what creates compounding. Constraining to *just these two* is how you avoid overwhelm at the start; the other moves here are *part of* the loops, not additional loops.

**They have to be lived, not read.** Reading about `/pickup` doesn't give you the experience of finding yourself already oriented in a session that started cold. Run them a few times and the muscle is yours.
